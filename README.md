## 🌐 How to Deploy to GitHub Pages in 60 Seconds

### Method 1: Push Directly to GitHub Repository
1. Open PowerShell / Command Prompt in `c:\portfolio`:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for 10/10 AI/ML portfolio"
   git branch -M main
   ```
2. Link to your GitHub repository (e.g. `HARIHRITHIK/HARIHRITHIK.github.io` or `HARIHRITHIK/portfolio`):
   ```bash
   git remote add origin https://github.com/HARIHRITHIK/portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment**, set **Source** to `Deploy from a branch`
   - Select branch `main` and folder `/ (root)`
   - Click **Save**
   - Your portfolio will be live at `https://harihrithik.github.io/portfolio` (or `https://harihrithik.github.io`)!
